### Description

```
Clawdia is a native iPhone companion for the Hermes AI agent. Connect securely to a Hermes host you operate—your Mac, a home Linux box, or a cloud VM—and keep your agent, projects, and automations close wherever you go.

Built for people who want the power of an autonomous agent without giving up control of where it runs. Clawdia connects directly to your host over SSH. Your chats, project files, and agent state stay between your iPhone and the machine you configure.

WHAT YOU CAN DO

• Chat in real time. Start or resume sessions, stream responses as they arrive, inspect reasoning and tool calls, switch models, attach images, and use voice mode.

• Work across projects. Browse project dashboards, sessions, boards, mini-apps, and sites. Start a project-scoped chat with the right repository context already loaded.

• Manage multiple hosts and profiles. Add SSH-reachable Hermes servers, switch between them, and select a profile without changing the host's active profile for other clients.

• Browse and edit skills. See installed skills, browse the skill hub, review updates, and inspect each skill's source and metadata.

• Monitor your agent. Review recent sessions, token activity, tools, scheduled jobs, plugins, webhooks, and gateway integrations from one native interface.

• Keep memory in reach. Read and edit your agent's memory files with clear saved-state feedback.

• Stay secure by design. SSH keys are generated and stored in the iOS Keychain. Clawdia has no advertising SDK and sends no analytics or telemetry to Sycamore.

PRIVACY

Clawdia does not collect or store your chats, credentials, project data, or agent state on developer-controlled servers. Connections go directly from your device to hosts you configure. Read the complete policy at awizemann.github.io/scarf/privacy.

REQUIREMENTS

• iOS 18.0 or later
• A reachable machine running Hermes Agent
• SSH access from your iPhone to that machine, through local Wi-Fi, VPN, Tailscale, or another route you control

Clawdia is open source under the MIT license. Source code, documentation, and issue tracking are available at github.com/awizemann/scarf.
```

## App icon

App Store Connect does not accept a separate profile-picture upload. It extracts the icon from the first processed build. The iOS target currently supplies:

```
scarf/Scarf iOS/Assets.xcassets/AppIcon.appiconset/Clawdia-AppIcon-1024.png
```

The source is 1024×1024, has no alpha channel, and is referenced by the target's `AppIcon` asset-catalog setting. It is derived from the supplied Clawdia pixel-art portrait.
